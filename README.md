# 서버(PP_01_04_Server)
이 프로젝트는 [Behind The Scene 시스템]()에서 모든 클라이언트를 연결하는 **중앙 서버 프로그램**입니다.</br>
체험 세션을 관리하고, 촬영 및 편집 과정에서 생성된 이미지를 저장하여 각 클라이언트(Studio, Editor, Gallery)에 필요한 데이터를 전달합니다.</br>
</br>
Server는 이 시스템에서 체험 흐름을 논리적으로 연결하는 중계 지점입니다.</br>
각 클라이언트는 직접 서로 통신하지 않고 모든 요청과 데이터는 서버를 통해 세션 단위로 관리됩니다.</br>
</br>


## 주요 기능
<ul>
  <li>세션 코드(고유 비밀번호) 발급</li>
  <li>세션별 원본 이미지 및 편집 이미지 관리</li>
  <li>클라이언트 요청에 따른 이미지 전달</li>
  <li>Studio · Editor · Gallery 간 데이터 중계</li>
</ul>
</br>

## 사용 기술
### 네트워크
<ul>
  <li>통신 방식: TCP Server</li>
  <li>라이브러리: Telepathy (Unity용 TCP 통신 라이브러리)</li>
  <li>설명: 이미지 데이터와 세션 정보는 TCP 연결을 통해 클라이언트와 서버 간에 이진 형태로 송수신됩니다.</li>
</ul>

### 데이터베이스
<ul>
  <li>DBMS: SQLite</li>
  <li>설명: 세션 코드와 이미지 파일 경로 등 체험 진행에 필요한 최소한의 메타데이터를 저장하는 데 사용됩니다.</li>
</ul>
